# Public Scope

This repository is an independently written reference implementation of a narrow lifecycle-policy pattern for agent memory.

It intentionally excludes:

- private product code and internal architecture
- customer information, operational records, and real examples
- credentials, secrets, endpoints, and infrastructure configuration
- proprietary names, trademarks, and internal terminology
- storage adapters, embeddings, retrieval systems, model providers, APIs, and user interfaces

The code demonstrates deterministic lifecycle decisions only. It is not a complete memory system and should not be treated as one.
